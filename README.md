# Авто Кодер

Приложение — это Ru Code; дальше в тексте просто «приложение».

Плагин запускает ваш скрипт `auto-coder` отдельным процессом для каждого проекта и показывает
его вывод в панели.

## Сборка

    pnpm install
    pnpm build

Результат — папка `dist/`. Это и есть плагин: внутри `plugin.json`, серверная и веб-части.

## Песочница

    pnpm dev

Открывает плагин в песочнице SDK с тестовым сервером, без приложения.

## Установка в приложение

Скопируйте `dist/` в папку плагинов приложения — `plugins/auto-coder/` внутри папки данных
приложения в вашем домашнем каталоге — и перезапустите приложение. То же одной командой:

    pnpm install-local

Чтобы удалить плагин, удалите эту папку.

## Проверки

    pnpm typecheck && pnpm lint && pnpm test
    pnpm test:e2e
